# YuyayRAG

YuyayRAG es una plataforma RAG empresarial de código abierto que permite a las organizaciones consultar su documentación interna mediante una interfaz de chat impulsada por inteligencia artificial.

Diseñada para desplegarse en la infraestructura propia de cada organización, permite a los colaboradores encontrar información relevante en documentos internos mediante consultas en lenguaje natural, manteniendo el control sobre sus datos.

La plataforma estará diseñada para ofrecer compatibilidad con modelos de lenguaje (LLM) a través de proveedores como Ollama y OpenAI, permitiendo utilizar modelos locales o servicios de IA mediante sus respectivas API.

## Estado del proyecto

YuyayRAG se encuentra actualmente en desarrollo. Todavía no hay una demo pública disponible en línea, pero se prevé publicarla próximamente.

La documentación de instalación, configuración y despliegue se ampliará a medida que avance el desarrollo.

## Tecnologías

- Backend: Flask, LlamaIndex, ChromaDB y Keycloak.
- Frontend: React.
